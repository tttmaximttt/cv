# CV.EXE

Maksym's CV, served from a retro MS-DOS PC with a round CRT monitor.

Open `index.html` in a browser, type `HELP` at the `C:\CV>` prompt, or press F1–F8 / ESC (F8 toggles sound).

## Commands

`ABOUT`, `SKILLS`, `PROJECTS`, `WORK`, `CONTACT`, `COLOR` (green / amber / white phosphor), `SOUND ON`, `CLS`, `EXIT`. Hidden commands exist.
